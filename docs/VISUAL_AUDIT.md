# 视觉审查报告与重制方案 (`docs/VISUAL_AUDIT.md`)

> 基准分支：`main` (`3922554`) | 开发分支：`feature/visual-overhaul`  
> 目标风格：**Grounded Medieval Fantasy / Atmospheric Western Fantasy RPG**

---

## 一、基线版本全面审查（代码与实机截图对照）

在无头 Chrome + SwiftShader WebGL2（1280×720）下对 `main` 分支进行了实机截图与代码审查（基线软件渲染帧率：`2 FPS`，大量非实例化几何体）。主要问题如下：

### 1. 场景、建筑与道具 (`WorldBuilder.ts`, `PropFactory.ts`, `DungeonBuilder.ts`)
| 文件 / 区域 | 基线问题 | 代码根因 |
| --- | --- | --- |
| 溪谷村建筑 (`WorldBuilder.ts`) | 铁匠铺与猎人小屋仅为单个 `BoxGeometry` 加 4 棱锥 `ConeGeometry` 屋顶，无门窗、石基、木框架、屋檐椽子与烟囱；村长长屋虽可进入，但墙面光滑无结构层次。 | `addBoxColliderAndMesh` 直接生成单块灰泥盒体，屋顶仅用旋转薄板或单圆锥。 |
| 村庄环境叙事 | 缺少石板路、木推车、货箱、木桶、木栅栏、路牌、街灯与工匠铁砧造型细节。 | 仅放置了 4 个立柱火盆与简化水井圆台。 |
| 废弃哨塔与墓穴外门 | 哨塔由素色长方体拼接围成，无扶壁、垛口与石砌纹理；墓穴外门缺少哥特拱门与石雕柱饰。 | 全部使用单一 `darkStoneMat` 纯色材质，未拆分建筑构件。 |
| 古代墓穴 (`DungeonBuilder.ts`) | 墙体与石柱毫无砖石质感，天花板平坦无拱肋，缺少石棺与壁挂火把支架。 | 平滑单色 `BoxGeometry` 与过高指数雾导致空间轮廓模糊。 |
| 交互道具 (`PropFactory.ts`) | 宝箱顶盖为平板盒子；拾取物脚下带刺眼的霓虹扁平圆环 (`RingGeometry`)，破坏写实沉浸感。 | 缺少弧形顶盖、锻铁包边、书籍封面细节与自然微光提示。 |

### 2. 材质、地形、植被与水体 (`TerrainGenerator.ts`, `SceneEngine.ts`, `DayNightCycle.ts`)
| 系统 | 基线问题 | 代码根因 |
| --- | --- | --- |
| PBR 材质与纹理 | 几乎所有建筑、地面、金属均使用无贴图的纯色 `MeshStandardMaterial`，近看呈现塑料质感。 | 缺少 `map` (SRGB Albedo)、`normalMap`（切线空间法线）与 `roughnessMap`。 |
| 地形与河谷 | 地形仅依赖低频顶点色，缺少近距离草地/泥土微纹理与河岸砾石过渡；水面无波纹法线高光。 | `PlaneGeometry` 无重复细节贴图与法线；水体仅靠整体 `position.y` 上下浮动。 |
| 森林植被 | 165 棵树均为独立 `Group`（每棵 2–4 个独立 Draw Call），树种单一（仅圆锥松树与二十面体树），地表完全没有灌木、蕨类、草簇与倒木。 | 未使用 `InstancedMesh` 合批与多物种变体，导致 Draw Call 过高且生态单调。 |
| 天空与光影 | 天空为纯色 `scene.background`；虽已设置 `ACESFilmicToneMapping`，但缺少天空穹顶着色器、太阳光晕、昼夜色温梯度与画质档位控制。 | `SceneEngine.ts` 与 `DayNightCycle.ts` 仅切换静态背景颜色与单一阴影尺寸。 |

### 3. 角色、敌人与第一人称武器 (`NPCSystem.ts`, `EnemyAI.ts`, `PlayerController.ts`)
- **NPC**：头、身、衣袍为简单几何块，缺少斗篷、围裙、箭袋、长弓、灯笼法杖与五官/胡须轮廓层次。
- **敌人**：哥布林、骷髅战士与墓穴守卫为直板方块拼装（骷髅无胸腔肋骨与脊柱轮廓，Boss 无重甲肩甲与符文巨剑细节）。
- **手持武器**：铁剑仅由 3 个未倒角矩形/圆柱拼接，更换武器后第一人称视角外观不会变化。

### 4. 游戏 UI / UX (`UIManager.ts`, `style.css`)
- **探索 HUD**：左下角生命/法力/耐力/经验被包裹在厚重的带框仪表盘矩形中；屏幕底部常驻 4 个网页风格按钮（`背包 [I]` 等），破坏沉浸感；顶部罗盘仅显示纯文本。
- **背包界面 (`baseline_05`)**：纯文本表格列表 + `1px` 金色边框，出现 `卸\n下` 按钮换行错位缺陷，缺少 SVG 图标、分类页签、稀有度区分与右侧详情面板。
- **NPC 对话 (`baseline_06`)**：居中弹出巨型矩形模态框，完全遮挡正在交谈的 3D NPC 模型。
- **世界地图 (`baseline_07`) & 任务日志**：地图仅为素底色块加空心圆圈，缺少等高线、山脉/森林地形符号与地理图例；任务日志未做主/支线双栏分栏。

## 二、全面重制架构与改造方案

1. **Phase B — 程序化 PBR 材质库与三档画质 (`MaterialLibrary.ts`, `QualityManager.ts`)**：
   - 使用 Canvas + Sobel 高度转法线算法生成全套平铺 PBR 贴图（石块鹅卵石、都铎灰泥、深色橡木梁、木板、石板瓦片、地形微表皮、地下城凿石、锻铁/精钢/青铜与水波法线），全部带 `SRGBColorSpace` Albedo、Normal Map 与 Roughness Map。
   - 新增 **Low / Medium / High** 三档画质切换（像素比、阴影贴图分辨率、植被密度、视距、雾效与粒子规模），并暴露实时 `FPS / Draw Calls / Triangles / Textures` 遥测面板。
2. **Phase C — 中世纪建筑与村庄叙事升级 (`ArchitectureBuilder.ts`)**：
   - 彻底重构溪谷村所有建筑与地标：带石砌基座、凸出木桁架框架、透光窗格、悬挑木瓦屋檐、椽子、烟囱的村长议事厅、铁匠铺与露天锻炉（含角砧/水桶/武器架）、猎人林屋（含木廊与箭靶）、带绞盘木桶的村井、石板路、木轮货车、木栅栏、三向路牌与街灯；同时升级废弃哨塔（扶壁、垛口与内部螺旋爬梯）、河谷石墩木桥与古代墓穴哥特入口。
3. **Phase D — 沉浸式 RPG UI 重制 (`UIManager.ts`, `IconRegistry.ts`, `style.css`)**：
   - **极简 HUD**：顶部天际风滑动罗盘带、左下流线型状态条与徽章、右上浮动任务追踪、底部 4 槽图标快捷栏（支持 `3`/`4` 键直接饮用药水），移除常驻网页按钮。
   - **全新菜单**：三栏式背包（装备槽+属性 / 分类过滤+图标列表 / 详情与操作）、下三分之一电影化 NPC 对话栏（保留 3D 角色视野）、羊皮纸等高线手绘风地图、双栏任务日志与含画质/性能监控的系统菜单。
4. **Phase E — `InstancedMesh` 生态、天空穹顶着色器、角色精修与地下城升级**：
   - 建立 `VegetationBuilder.ts`：松树、灰木橡树、枯树三类树种加上灌木、蕨类、草簇、倒木共千余实例通过 `InstancedMesh` 批处理渲染。
   - 天空穹顶自定义 GLSL 着色器（日出/正午/日落/星夜渐变与太阳辉光），水体波动法线材质，古代墓穴肋拱、石棺、壁挂火把架与符文祭坛，全面重塑 NPC、敌人骨骼网格及动态切换的第一人称剑模。
5. **Phase F — 视觉对比、性能实测与 Pull Request**：
   - 采集 7 组改造后截图对比、三档画质性能对照表与回归测试结果，向 `main` 提交 PR（不直接合并覆盖在线版本）。

## 三、重制前后实测性能与画面对比

### 1. 性能与渲染指标实测（1280×720 Chrome + SwiftShader WebGL2 软件渲染）

| 版本 / 画质档位 | 平均帧率 (FPS) | 单帧耗时 | Draw Calls | Triangles | Textures | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| **重制前基线 (`main`)** | 2 FPS | ~500 ms | ~600+ | ~42,000 | 0 (纯色) | 165 棵非合批树木 + 42 块岩石各自独立 Draw Call，无 PBR 贴图 |
| **重制后 High 档** | 23–60 FPS | 16.7–42.8 ms | 503 | 130,864 | 40 | `InstancedMesh` 合批植被（190 棵多树种 + 760 灌木草簇岩石），2048px 阴影，全 PBR 法线/粗糙度贴图 |
| **重制后 Medium 档** | 22 FPS | 44.8 ms | 503 | 112,500 | 40 | 75% 植被密度，1536px 阴影，视距 380m |
| **重制后 Low 档** | 22 FPS | 44.8 ms | 503 | 90,520 | 40 | 45% 植被密度，1024px 阴影，视距 260m（SwiftShader 下帧率受像素填充限制，真机独立/核显 GPU 上画质降档收益更显著） |

> 注：以上数据为同一台主机在 Playwright 无头 Chrome（SwiftShader CPU 软件 WebGL2）实测输出；真实桌面硬件 GPU 的绝对帧率需待人工在物理机浏览器实机体验确认。

### 2. 视觉改造前后直观对比（截图留档）

- **溪谷村 (`baseline_01_village.png` vs `overhaul_01_village.png`)**：从单块素色方盒与圆锥屋顶，全面升级为石砌基座 + 凸出深色橡木桁架 + 灰泥墙 + 透光木窗框 + 悬挑木瓦屋檐与烟囱的中世纪建筑群，广场铺设鹅卵石路并新增石砌带顶水井、辐条木轮货车、街灯立柱、铁匠露天锻炉角砧与猎人箭靶。
- **探索与河谷 (`baseline_02_explore.png` vs `overhaul_02_explore.png`)**：水面升级为法线波纹动态高光水体，木桥加装石桥墩、水下木桩与双层木栏杆，远景呈现天空穹顶渐变与雪山轮廓。
- **灰木森林 (`baseline_03_forest.png` vs `overhaul_03_forest.png`)**：通过 `InstancedMesh` 合批渲染北方松树、灰木橡树与枯木三类树种，配合灌木、蕨类草簇与河岸砾石，并增加哥布林营地尖顶帐篷与盾牌弯刀哥布林造型。
- **古代墓穴 (`baseline_04_dungeon.png` vs `overhaul_04_dungeon.png`)**：石墙与湿润地砖接入 PBR 法线与粗糙度贴图产生火把反光，通道增加肋拱石梁、雕刻柱头、石棺与蓝光符文祭坛，骷髅战士呈现真实肋骨/脊柱/颅骨轮廓。
- **UI/UX 系统 (`baseline_05..07` vs `overhaul_05..08`)**：移除底部网页按钮条与全屏表格仪表盘，重构为天际风顶部滑动罗盘、左下极简状态条、底部 4 槽图标快捷栏（支持 `3`/`4` 键喝药）、三栏式带 SVG 图标及详情面板的背包、下三分之一电影化 NPC 对话框、双栏任务日志、等高线羊皮纸地图及内置画质/性能监控的系统菜单。
