# 游戏设计文档 (GDD) — Ashen March：灰烬边境

## 1. 游戏概述

- **游戏名称**：Ashen March — 灰烬边境
- **类型**：第一人称 3D 西方奇幻单人动作角色扮演游戏（Action RPG）
- **核心设计支柱**：
  1. **系统驱动而非脚本演出**：战斗、AI、背包、装备、任务、商店与存档均围绕统一状态机与 JSON 配置运作。
  2. **真实的空间探索感**：基于 3D 地形高度场与碰撞体构建可攀爬高地、可进入房屋与独立地下城。
  3. **轻量化可长期扩展框架**：程序化几何体与着色/粒子表现保证在无外部商业资源的前提下快速加载并稳定运行。

## 2. 世界观与区域设计（512 × 512 米）

玩家的旅程始于北境边缘的**灰烬边境**——一个曾由“守望者”结界庇护的偏远谷地。近来亡灵在森林边缘出没，废弃多年的东部哨塔重新燃起了警示火光，北方山麓下的古代墓穴石门也悄然开启。

### 区域一览
1. **溪谷村 (Ravendale Village)** `(0, 40)`
   - 安全起始区域。
   - **可进入建筑**：村长长屋（包含室内壁炉光源、木桌、长椅、宝箱与壁挂旗帜）。
   - **其他建筑**：铁匠铺、猎人木屋、村庄石井与守望火盆。
   - **NPC**：村长奥尔德林、铁匠商人葛伦、猎人莱拉。
2. **灰木森林 (Ashwood Forest)** `(-105, -25)`
   - 起伏丘陵与多层次针叶/阔叶/枯木林。
   - **敌人**：灰木哥布林巡逻营地。
   - **探索要素**：灰烬草采集点、战利品宝箱、西部深处的**隐秘祭坛**。
3. **废弃哨塔 (Ruined Watchtower)** `(105, -65)`
   - 坐落于东侧高地（海拔 ~14m）的可进入圆塔遗迹。
   - **探索要素**：螺旋/斜坡通道、燃烧的烽火台、主线关键线索道具《守望者日志》、哥布林哨兵与补给箱。
4. **古代墓穴 (Ancient Crypt)** 入口 `(0, -175)` -> 独立地下城空间
   - 独立地下城场景：石壁长廊、符文石柱、摇曳壁灯、侧翼藏宝室与主墓室圣坛。
   - **敌人**：骷髅战士、Boss **墓穴守卫·阿卡索尔**。
   - **核心战利品**：守望者圣物箱（内含《守望者圣物》）与符文武器。
5. **河谷区域 (River Valley)** `(95, 75)`
   - 自北向南贯穿东部谷地的浅河道与木桥，两岸散布岩石、灰烬草及河畔宝箱。

## 3. 核心战斗与 RPG 数值体系

- **基础属性**：
  - `HP`（生命值）：归零后在溪谷村复活（保留当前物品与任务进度）。
  - `MP`（法力值）：随时间缓慢恢复，用于施放法术。
  - `Stamina`（耐力值）：奔跑消耗，停止奔跑后恢复。
  - `Attack` / `Magic` / `Defense`：由基础成长值 + 装备属性 + 剧情祝福共同构成。
- **战斗方式**：
  - **单手剑近战**：挥砍冷却 `0.55s`，距离判定 `3.2m`，前向夹角余弦 `>= 0.35`，命中产生击退与火花粒子。
  - **火球术**：消耗 `15 MP`，冷却 `0.9s`，发射带动态点光源与尾迹粒子的火球弹体，接触敌人或障碍物时产生范围/单体伤害与爆炸特效。
- **成长体系**：击败敌人与完成任务获得 `XP`，升级时提升最大生命、最大法力与基础攻击/魔法/防御。

## 4. 任务与剧情分支设计

### 主线任务：《失落的守望者》(`main_lost_watchers`)
1. **阶段一 (`investigate_watchtower`)**：与村长奥尔德林对话，前往东部废弃哨塔调查异常火光，拾取《守望者日志》。
2. **阶段二 (`explore_crypt`)**：根据日志指引前往北方山麓进入古代墓穴，击败墓穴守卫·阿卡索尔，开启圣坛宝箱获得《守望者圣物》。
3. **阶段三 (`return_to_elder`)**：带着圣物返回溪谷村向村长禀报，做出关键剧情抉择：
   - **结局 A — 交还圣物 (`return_relic`)**：消耗圣物重塑边境结界，获得 `300 XP`、`250 金币` 与永久祝福（`+5 防御`、`+25 最大生命`），村长致敬守护者。
   - **结局 B — 保留圣物 (`keep_relic`)**：将《守望者圣物》留为己用（可装备饰品 `+12 攻击 / +15 魔法 / +6 防御`），获得 `200 XP`，村长发出警示，游戏记录 `ending_renegade` 标记。

### 支线任务
- **《灰木林的威胁》(`side_goblin_menace`)**：在猎人莱拉处接取，消灭灰木森林中的 3 名灰木哥布林，回报获得 `120 XP`、`100 金币` 与 `猎人短剑`。
- **《边境物资筹备》(`side_frontier_herbs`)**：在铁匠商人葛伦处接取，收集 3 株 `灰烬草`，回报获得 `90 XP`、`80 金币` 与 2 瓶 `强化治疗药水`。
