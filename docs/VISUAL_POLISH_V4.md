### 1.2 逐机位视觉缺陷根因诊断（基于真实截图检视）

1. **石墙与拱券的“巧克力砖块 / 枕状倒角”与子砖缝切割（Cam A / B / D / E / F / H — P0）**：
   - V3 旧贴图（`stone_brick_wall_v2` / `citadel_masonry` / `limestone_weathered`）使用过宽的圆滑倒角梯度与高饱和铁锈棕/蓝灰随机跳色，导致墙面像圆鼓鼓的塑料积木。
   - 更严重的是：`limestone_weathered` 内部自带砖格缝隙，贴在 3D 雕刻的拱券楔石（Voussoirs）与城垛石块上时，单块 3D 巨石表面被切出多条假砖缝（见 `before_camB`、`before_camH`）。
2. **建筑与山体的程序化 `add_box()` 拼装感（Cam A / B / C / H — P0）**：
   - `before_camC` 与 `before_camH` 中，市集北壁上方的“山崖”实际是若干个做过 `bevel=0.45` 的巨大灰色圆角长方体（`add_box("mountain_crag_rock")`），顶上坐着像玩具积木盒一样的远景主堡。
   - 门洞、窗洞、桥底缺少真正的哥特多层退台拱券（Molded Archivolts）、肋架拱顶（Ribbed Vault）以及石块缺角/收分（Batter）雕刻形体。
3. **石板路呈扁平 2D 细胞图 + 路肩垂面 UV 严重拉丝（Cam G — P0）**：
   - `before_camG` 中，`broken_flagstone` 呈现规则光滑的 Voronoi 多边形色块，接缝处围绕一圈均匀绿线，缺乏石板微倾角、次级断裂、表面凿痕与碎石凹槽。
   - 画面左侧 `CityGroundBuilder` 台地垂裙仅用平面 `(x, z)` 投影 UV，导致垂直立面出现严重的纵向条纹拉丝；道路与墙根呈一刀切直角相交，没有路缘石（Curbstones）和排水沟（Drainage Gutter）。
4. **发光方块占位符与镀铬质感的锻铁材质（Cam B / C / F — P0/P1）**：
   - `before_camF` 正中央壁灯内悬浮着一块扁平肉粉色八角块（`glow_warm`），火盆顶上也放着橘色发光方块（`before_camB` 右下角）；壁灯外框因 `metalness = 0.82` 且缺少空间变化的 Packed ORM 金属度/粗糙度贴图，呈现出不自然的液态镀铬镜面反射。
   - `CityMaterialLibrary.ts` 的 `loadOrmPBR` 仅绑定了 `roughnessMap`，未绑定 `metalnessMap` 与 `aoMap` 通道。
5. **旧城区建筑配色割裂（Cam C / D — P1）**：
   - 市集东西两侧旧资产仍保留高饱和橙红瓦顶、薄荷绿灰泥墙与马戏团式红白/黄白条纹遮阳篷，与灰岩山城基调严重冲突。
6. **正午太阳近乎正南平射 + 室内外天光无衰减（Cam A / C / E — P1）**：
   - `13:00` 城市太阳方位角仅偏离正南约 `4°`（X 分量 `-5.6` vs Z `+42`），导致所有朝南城墙、扶壁与拱门缺乏斜向侧光体积阴影。
   - `before_camE` 中，`CityAmbientProbe` 的室外天空球谐漫反射（`gain = 2.1`）无遮挡穿透进酒馆室内，导致室内门框石墙与门外街道几乎同等明亮，丧失室内外明暗冷暖反差。

## 二、V4 精修方案与两轮真实画面迭代计划

1. **P0 材质与着色器重构（1024×1024 Hero 贴图集 + Packed ORM 完整绑定）**：
   - 使用原生 C 程序 `scripts/city/texgen_v4.c` 生成具有 **宏观矿脉/水渍 + 中观窄灰缝/垫片碎石（Galleting）/石块微倾法线 + 微观凿痕/砂粒孔隙 + 8 向高度场 HBAO + 双尺度法线** 的 1024×1024 / 512×512 贴图集。
   - 彻底区分 **整块雕凿条石（`limestone_weathered`，零假砖缝）** 与 **多排错缝城垣砌体（`citadel_masonry`）**。
   - 统一旧建筑灰泥、板岩瓦与织物色调，接入完整 `R=AO, G=Roughness, B=Metalness` ORM 通道与切线空间支持。
2. **P0 建筑与山崖 BMesh 雕刻化重构（`scripts/city/stormveil_kit.py`）**：
   - 实现 `bmesh` 细分与有机裂理位移：28° 倾角层理裂解山崖（取代圆角方块山体）、敲击缺角条石、收分扶壁、哥特多阶退台尖拱、桥底十字肋拱、炭木余烬火盆与锻铁灯笼笼架（彻底移除肉粉色发光方块）。
3. **P1 三大样板区（南门 / 窄巷石桥 / 市集北壁山崖交界）环境精修**：
   - 增加雕凿路缘石、下凹排水沟与铁箅、墙根散落碎石与杂草、窄巷木撑与挑檐、市集摊位货物组合、酒馆木桶柴堆与城门武器架拒马。
   - 修复 `CityGroundBuilder.ts` 台地垂壁 UV 拉丝，增加路面微起伏与路沟凹陷。
4. **渲染管线四阶段验证、斜射光影、室内外天光遮蔽与分房间裁剪**：
   - 调整 13:00 太阳至西南约 `38°` 斜射方位角，为酒馆/卫兵室/`-4m` 暗渠注入平滑世界空间室内天光遮蔽（Sky Occlusion），实现分区域静态批次与室内房间裁剪，并输出管线 4 阶段对比图与两轮迭代对比。

### 3.2 Iteration 1 已验证改善项 vs 仍需在 Iteration 2 彻底解决的缺陷

**已确认显著改善**：
- **山体与城堡远景彻底摆脱方块感（`Cam C` / `Cam H`）**：圆角方块山体已被 28° 倾角层理裂解山崖替代，山顶旧玩具盒主堡替换为不对称哥特高层要塞群；`Cam H` 斜切 30° 砖纹已修正为水平错缝砌体嵌合岩壁。

**Iteration 1 严格挑刺（必须在 Iteration 2 逐项解决）**：
1. **`limestone_weathered` 法线贴图残留规则斜向“灯芯绒”凿纹（`Cam F` 1m 近景、`Cam G` 路缘石）**：`texgen_v4.c` 中 `gen_limestone_weathered` 仍含周期正弦波纹，1m 近看呈规则平行条纹；且反照率偏粉白，叠加在深色墙面上像孤立白砖块（`Cam B` 桥头、`Cam E` 门外墙面、`Cam F` 壁灯后方）。
2. **`damp_slate_stone` 呈深黑油亮细胞斑纹（`Cam A` 门洞下部、`Cam F` 壁龛背板、`Cam H` 中柱）**：粗糙度偏低且高度图含类 Voronoi 细胞凹坑，近看像深褐蛇皮块而非劈裂青灰板岩。
3. **`broken_flagstone` 路面灰缝偏亮、石板明度过于一致（`Cam G`、`Cam A`）**：缺少成排错缝大石板与深色潮湿泥苔灰缝的明暗对比，仍略带均匀多边形网格感。

5. **`Cam H` 台阶侧面斜向压条像细长白木板**：需改为随台阶水平跌落的阶梯状压顶条石；`Cam B` 垂挂藤蔓仍呈规则竖排方片，需改为自然斜向攀附常春藤簇；`Cam E` 门口住客名册交互提示遮挡门洞中心构图。
6. **Draw Calls 与 Shadow Pass 尚未裁剪地底暗渠与远端街区**：`-4m` 暗渠与全城道具批次仍在地面机位参与主通道与阴影通道渲染，需在 Iteration 2 实装分房间/地底裁剪与分街区道具批次。

## 四、V4 Iteration 2（Final）针对性精修与性能验证（`after_camA..H.png`）

针对 Iteration 1 暴露的 6 项问题，在 Iteration 2 中完成了资产级与着色器级闭环修复：
1. **彻底消除 `limestone_weathered` 规则斜纹并统一石材明度**：移除 `scripts/city/texgen_v4.c` 中所有周期正弦波，改为沉积层理、浅剥落片与微孔裂纹，并将风化灰岩明度收敛至 `0.44–0.54` 区间，与 `citadel_masonry` 自然融合（消除孤立白骨牌感）。
2. **`damp_slate_stone` 重构为层状劈裂高地青灰板岩**：移除细胞状 Voronoi 凹坑与过低粗糙度（`0.32 → 0.58–0.88`），恢复真实层状页理台阶（`Cam A` 门洞基座、`Cam F` 壁龛背板、`Cam H` 中柱质感显著提升）。
3. **`broken_flagstone` 升级为多岩性错缝石板 + 深凹泥苔暗缝**：引入暖灰岩、冷青石板与陈旧灰石的逐板明度/冷暖差异，灰缝降为深湿泥苔色（`0.15–0.21`）并叠加高程凹陷 HBAO（`Cam G` 彻底告别灰白细胞网）。
4. **重塑哥特市集喷泉、宪章柱与 6 座木构粗麻摊位（`Cam C` / `Cam D`）**：在 `stormveil_kit.py` 中以雕凿八角压顶石、扶壁角柱、铁链石桩、狮首铁流口与哥特尖顶重制 `landmark_market_fountain.glb`；全部 6 座摊位与宪章柱换装锻铁六角笼灯与褪色粗麻篷布（**全城零肉粉/橘色发光方块占位符**）；旧城区灰泥、瓦顶与布幔材质全部收敛至史东薇尔风化灰褐体系。
5. **台阶水平阶梯压顶条石、斜向攀援常春藤与 `Cam F` 壁龛柳叶窗雕花**：`add_stone_stair_flight` 改为逐段水平悬挑压顶条石（解决 `Cam H` 斜向白木条感）；`Cam F` 壁龛背板雕刻双联哥特石棂与祭台融蜡短烛；`Cam E` 住客名册移至吧台（保留完整交互同时释放门洞中心构图）。
6. **分房间室内裁剪、`-4m` 地底暗渠入口裁剪与南北道具批次拆分（`CityPhase1Builder.ts`）**：
   - `-4m` 暗渠（`CityZone_UndercroftSublevel`）仅在玩家位于地下（`y < 0.85`）或距南北楼梯口 `11.5m` 内渲染；
   - 酒馆与药剂坊室内家具改为静态合并批次并按门窗 AABB 裁剪；
   - 全城道具拆分为南北两区批次，小型散落地面道具关闭方向光 `castShadow`（保留烘焙 BVH 顶点 AO + HBAO 贴图与 `receiveShadow`）；烟囱烟雾精简为 8 个按距离裁剪粒子。

## 五、渲染管线四阶段验证与材质诊断（`pipe_1..4` & `diag_*`）

针对 `Cam A` 实机输出的 4 个管线阶段验证（归档于 `docs/screenshots/v4/pipe_1..4_*.png`）：
1. **`pipe_1_raw_no_post`（无后处理线性直出）**：基础光比、阴影深度与石材固有色本身已具备清晰明暗体积感，不依赖任何滤镜兜底。
2. **`pipe_2_tonemap_only`（仅 Khronos PBR Neutral Tone Mapping）**：自然收敛受光石灰岩拱券与天空交界的高光动态范围，保持石材冷暖色相零偏色。
3. **`pipe_3_tonemap_fxaa`（Tone Mapping + 亮度边缘 FXAA）**：消除铁闸门、石拱斜向肋架与剑刃边缘锯齿，同时保留石块灰缝结构。
4. **`pipe_4_final`（叠加无光晕自适应微锐化 `0.18` + 极弱 8-bit 防色带抖动 `0.0025`）**：略微补偿 FXAA 对近景石材砂粒法线的柔化，无黑边/白边锐化光晕，无脏噪点颗粒感。
