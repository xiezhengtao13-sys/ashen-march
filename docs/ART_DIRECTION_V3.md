## 一、参考项目 `saltline-fable-5.2` 真实技术源码审计

以下严格区分**直接阅读 `realcodebear/saltline-fable-5.2/index.html` 验证存在的技术实现**与**面向 Ashenhold 西幻山城的原创迁移方案**（不复制任何受保护源码或美术资源）：

### 1.1 已从 Saltline 源码证实的技术机制（Verified Facts）
1. **GPU 程序化 Albedo + Packed ORM + 物理缩放法线生成**：
   - 使用 WebGL2 MRT (`WebGLRenderTarget` `count: 3`) 离屏同时输出 Albedo、Packed ORM（`R=AO`, `G=Roughness`, `B=Metalness`，单张贴图复用于 `aoMap`/`roughnessMap`/`metalnessMap`）与高度图，再经独立法线 Pass 按实际平铺尺度计算法线强度 `uK = bump * 0.001 * size / tile`。
2. **`SL_TRIPLANAR` 锐权三平面映射与 `SL_FX` 世界空间 3D 噪声宏观风化**：
   - 三平面采样使用 `pow(abs(normal), vec3(6.0))` 锐化混合权重，避免斜面模糊。
   - **双频世界空间 3D 值噪声 (`slN3`)**：叠加宏观明暗变化与受 ORM 缝隙 AO `(1.0 - slORM.r)` 放大的污垢遮罩 (`slGr`)，消除同材质建筑表面的机械平铺感。
3. **朝向与高度驱动的物理湿润 + 竖直雨痕 + 室内干燥屏蔽**：
   - 顶面受雨 (`smoothstep(0.15, 0.85, worldNormal.y)`)、竖直面各向异性拉伸 3D 噪声雨痕 (`slStreak`)、近地溅水湿润带 (`smoothstep(0.5, 0.0, worldPos.y)`)；
   - 室内材质通过 `uSlX.x = 0.12` 抑制户外潮湿；
   - 湿润区物理响应：略微提升饱和度、压低漫反射 Albedo、降低 Roughness，并在水膜/积水处提高介电质镜面反射率 `specularColor (0.04 → 0.075)`。
4. **地面多尺度着色 (`apron_wet` `TR/AR`)**：
   - 4-tap B-Spline 双三次滤波 (`gBicubic`) 采样宏观遮罩，杜绝近距离块状像素边；
   - 低频 (`0.21`) + 高频 (`1.37`) 双频率平铺纹理叠加 + `fwidth()` 抗锯齿接缝与裂纹；
   - 连续积水过渡梯度：**积水镜面 → 深色湿润水边带 → 潮湿区 → 干燥区**，边缘用多尺度世界空间噪声打碎（最低至 ~5cm）。
5. **轻量后处理管线 (`iA` Final Pass)**：
   - 在 LDR 阶段执行单 Pass 组合：**基于亮度对比度的轻量 FXAA** + **在强边缘自动回退的对比度自适应锐化（Unsharp Mask）** + **轻微胶片颗粒/抖动**，且均支持开关控制。

### 1.2 Ashenhold V3 原创迁移设计（Adapted Original Architecture）
- **保留晴朗白天为主调**：不照搬雨夜港口滤镜；在 13:00 晴朗日光下，将 Saltline 的“世界空间双频宏观风化 + 缝隙污垢 + 墙脚湿润/粗糙度变化 + 竖直雨痕 + 顶面青苔累积 + 三平面微细节”全部迁移为**原创中世纪哥特风化灰岩与山城石砌着色器 (`CityMaterialLibrary.ts`)**。
- **Packed ORM 通道与无焙影 Albedo**：离线 C99 生成器 (`scripts/city/texgen_v3.c`) 重写 6 套核心山城 PBR 材质（**禁止在 Albedo 中画粗黑卡通砖缝！** 改为真实风化浅灰/微暖灰砂浆缝、细裂纹、石孔砂粒与无方向阴影的纯基底色），并输出打包 ORM（R=微缝 AO、G=物理粗糙度、B=金属度）与高精度切线法线。
- **独立可开关后处理与 6 档材质诊断模式**：新增 `CityPostFX.ts`（支持 `fxaa` / `sharpen` / `grain` / `grade` 独立开关）与 `setDebugMode('final' | 'albedo' | 'normal' | 'roughness' | 'no_ao' | 'no_post')`。

## 三、V3 核心改造架构（Stages B–E）

### 3.1 根本改变建筑建模方式 (`scripts/city/stormveil_kit.py`)
废弃“纯整齐 `add_box()` 拼接重要石墙”的做法，在 Blender `bmesh` 中建立 **Sculpted Gothic Masonry Engine**：
- **逐块真实凹凸砌石 (`add_sculpted_stone_wall`)**：按真实错缝石层生成长短各异的实体石块，每块施加随机法向凸出（`±2.5–7.5 cm`）、微倾角、削角倒角与顶点随机侵蚀扰动，夹杂修补缺口、深陷箭孔、外突阶梯扶壁（Stepped Buttresses）、加厚斜坡基石（Battered Plinth）与残缺古垛口（Weathered Merlons）。
- **六大 Hero Assets**：
  1. `sv_hero_gate_tower.glb`：厚重史东薇尔式山城主门楼与多级守卫塔（含**可进入底层卫戍室 → 塔内石阶直上 `+9.5m` 城墙步道 → 继续攀升至 `+19.5m` 瞭望塔顶平台**）。
  2. `sv_hero_gothic_bridge.glb`：横跨 `4.5m` 窄石巷的尖拱哥特过街石桥（`+9.5m` 上层石砌步道直接从玩家头顶横跨而过，带石肋拱、悬臂石托、木栈护栏与铁拉杆）。
  3. `sv_hero_market_bastion.glb`：市集北侧 `11m` 高厚重风化扶壁城墙、底层凹入式石拱廊商铺（带柱廊拱顶）、不规则折返大石阶（`+3.5m → +9.5m`）及贴壁外阶直抵 **`+19.5m` 塔楼与城堡外墙平台**。
  4. `sv_hero_undercroft.glb`：位于底层之下 **`-4.0m`** 的哥特拱顶石砌地下排水通道/地窖（由市集石阶下探进入，带湿滑石渠、铁格栅排水沟、摇曳火把与隐藏补给箱，另一端沿石阶通回贸易主街/酒馆地窖）。
  5. `sv_hero_tavern_v3.glb`：厚重石基+老橡木双层酒馆（带侧窗透光、壁炉/吧台/吊灯/酒桶/餐桌丰富内饰、内梯直上二楼后门天桥连入 `+9.5m` 上层街巷）。
  6. `sv_hero_cliff_buttress.glb` + 近景叙事道具群（不规则堆石、断柱石凳、铁链壁灯、攀墙藤蔓/墙角杂草、石龛雕刻、木质脚手架支撑）。

### 3.2 四层实机连续垂直样板区（`~44 m × 62 m`，零传送全步行联通）
- **地下层 (`-4.0 m`)**：石砌拱顶排水地下通道（市集下梯 → 湿石地渠 → 主街侧出口上梯）。
- **底层 (`0.0 m → +3.5 m`)**：南城门 → 4.5–5.5m 贴高石墙窄巷（头顶 `+9.5m` 哥特石桥横跨）→ 酒馆/卫兵塔入口 → 紧凑石拱廊市集广场 (`+3.5m`)。
- **中层 (`+9.5 m`)**：上层城墙步道 & 过街哥特石桥（可经**守卫塔内梯**、**酒馆二楼连廊**或**市集北墙折返石阶**三条非传送路径抵达，低头直视刚走过的窄巷与市集）。
- **上层制高点 (`+19.5 m`)**：由 `+9.5m` 北城墙沿厚重扶壁贴墙石阶与瞭望塔攀升至 **`+19.5 m` 塔楼与城堡外墙平台**，俯瞰全样板区四层立体结构，并设有快速木栈阶梯捷径返回中层与市集。
